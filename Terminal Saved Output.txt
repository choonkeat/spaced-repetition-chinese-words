3. The parsed file data is stored into localStorage. Below the <input type=file>, we show how many words are in localStorage and provide a little trash icon to clear it
4. Uploading another file will append to this data; duplicate word is discarded

Clicking “Play”, the webpage will pick the next scheduled word to play. If the user gets it wrong, the word gets scheduled to be retried soon. If the user gets it 
correct, the word gets scheduled to be retried later. The next word appears and the logic repeats. We want to implement the delays such that it is in line with how spaced
 repetition is done.

How does a user “play” a card? There are actually 2 ways to play a card, and we should record the tries/success/failure separately. 

For each flashcard, we must test whether the User can “read” and “write”. 

Testing “read”
1. It will display flashcard.word as title and flashcard.sentence as body.
2. There is a “I don’t know” button: when tapped, use browser text to speech to speak flashcard.sentence aloud 1 time at 0.7x speed, and 1 more time in 1x speed. Then 
reveal “Next card” button
3. Tapping “Next card” button will go to next card
4. It will wait for the User to pronounce the sentence — I think we can detect User pronouncing the sentence by using the browser’s speech to text keyboard (please 
suggest) and type into a text field (auto focus).
5. If the words did not match, reveal the flashcard.word_hanyupinyin below flashcard.word, flashcard.sentence_hanyupinyin below flashcard.sentence, clear the speech to 
text input and loop back to (4)
6. If the speech to text words matches flashcard.sentence, then it is correct and we show a confetti effect along with revealing the “Next card” button

Testing “write”
1. It will display flashcard.word_english as title and flashcard.sentence_english as body.
2. There is a “Show answer” button: when tapped, reveal flashcard.word + flashcard.word_hanyupinyin below flashcard.word_english and flashcard.sentence + 
flashcard.sentence_hanyupinyin below flashcard.sentence_english.
3. Then reveal “Correct” and “Wrong” button; tapping either will proceed to next card
4. Tapping “Correct” will show a confetti effect before proceeding to next card
